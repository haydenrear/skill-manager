checkout with NO Skill Manager home, and an agent launched there writes the
operator's global one. This is green only when the replayed command produced
`<worktree>/.skill-manager/bin/cli` -- the worktree AND its home, from one
command, which is what `skt ticket new` promises over the hand-run pair.
