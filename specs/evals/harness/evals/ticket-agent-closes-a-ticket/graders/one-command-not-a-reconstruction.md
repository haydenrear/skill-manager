COST. Teardown is one command in every repo shape, because it resolves a ticket
by SEARCHING rather than by a path convention -- so even a hand-made worktree is
found. An agent running `home close-out && git worktree remove` by hand is
spelling out what the wrapper does, and the `&&` is load-bearing: on separate
lines the removal runs whatever the gate returned.
