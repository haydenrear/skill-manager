CAN A HOOK WRITE WHERE BASH CANNOT? The Bash tool is refused at cwd, $TMPDIR,
$HOME and under .git -- four measurements, two cases. If a Stop hook can write
this file in the same workspace, then verdict-path grading is available and
every write-dependent case has a way to be graded. If it cannot, nothing in
this suite can be graded on a file the run was supposed to produce.
