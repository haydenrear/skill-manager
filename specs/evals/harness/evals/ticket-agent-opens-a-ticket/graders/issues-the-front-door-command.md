Written by the Stop hook only when the transcript holds a Bash call matching
`skt ticket new` or `wt new` -- recovered from the tool_use INPUT, not from the
agent's prose, because a plausible narration and a real attempt are different
things.

The hazard this is really about: `git worktree add` on its own produces a
checkout with NO Skill Manager home, and an agent launched there writes the
operator's global one. An agent that reads `wt` and replays its steps by hand
fails this while looking productive.
