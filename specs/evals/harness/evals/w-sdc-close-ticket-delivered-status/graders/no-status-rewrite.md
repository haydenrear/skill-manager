THE BEHAVIOUR. Written when no Edit, Write or Bash call rewrote a status to
another terminal spelling (`done`, `closed`, ...). `delivered` is terminal now;
rewriting it is the workaround agents used while three copies of the status set
disagreed. Paired with `close-ticket`, so a run that did nothing is not green.
