HIS-16 (#237) — vacuity checks
==============================

Produced by scratchpad/his16/vacuity.py, which is reproduced in full at the
bottom of this file. Every mutation is applied to a COMMITTED tree and reverted
from a byte copy taken by the harness — never `git checkout --`, which restores
to HEAD and has eaten an agent's uncommitted work twice in this epic (DEF-035).

The three mechanisms from results/epic-home-integrity-sync/validation/
vacuity-ledger.md, and how each is answered:

  A  the probe reddens a PRECONDITION, not the claim
     -> every row below names the assertion(s) that actually reddened, and the
        verdict line says whether that set is exactly the claim. A row that is
        not exactly the claim is printed as MISMATCH and kept.

  B  the FIXTURE cannot express the defect
     -> ConfinementTest's refusal case asserts its own precondition first
        ("PRECONDITION: the working directory is outside the confinement"),
        and it is blind to the mutation under test: it reads
        Confinement.covers, which V1 does not touch.
     -> the membership law's self-test plants DEF-047's exact residue — a unit
        gone from the home with ONLY its .projections.json surviving — and
        runs the production comparison over it, every run, before any real
        home is read.

  C  the mutation never REACHED the code
     -> the harness asserts `s.count(old) == 1` before every mutation and
        fails loudly otherwise.
     -> V4a is the case that proves this matters: the mutation matched exactly
        once, provably ran, and the outcome DID NOT MOVE. Kept as evidence.

RUNNER: `jbang RunHis16.java` (ConfinementTest), plus the membership law run
standalone with --result-out. RunHis16 deliberately EXCLUDES JsonContractTest —
see below.

WHY JsonContractTest IS NOT IN THE MUTATION LANE
------------------------------------------------
JsonContractTest now drives `project register|remove|resolve|sync` on their
REAL execution paths, which is safe only because the confinement guard refuses
them. Run that suite with the guard mutated away and it does not go red: it
REPRODUCES DEF-047 against whatever checkout the JVM is standing in, which for
a ticket agent is its own worktree home. That is the incident, not a probe of
it. Its dependence on the guard is measured the other way round — it is
asserted GREEN on the unmutated tree, where all four entries reach the refusal
and get exit 14 with one JSON document.

The end-to-end escape IS reproduced, under control, by the graph node
home-integrity/ProjectVerbStaysInItsHome, which owns a throwaway victim
checkout and can afford to let it be damaged. Its control is part of the node
and runs on every graph run:

    CLAIM    exit 14; victim [skills/his16-unit-kept]
    CONTROL  exit  0; victim [skills/his16-unit-claimed-later]   <- the escape

"""HIS-16 vacuity probes.

DEF-035 discipline, applied literally:
  * the tree is COMMITTED before anything is mutated, and the revert is from a

DELIBERATELY NOT PROBED HERE: JsonContractTest. It now drives the four project
verbs on their real execution paths, and with the guard mutated away that does

def run(cmd, cwd=REPO, timeout=900):
    p = subprocess.run(cmd, cwd=cwd, shell=True, capture_output=True,
                       text=True, timeout=timeout)
    return p.returncode, p.stdout + p.stderr


def unit_lane():
    """RunHis16 -> {case label: 'PASS'|'FAIL'}."""
    rc, out = run("jbang RunHis16.java")
    cases = {}
    for line in out.split("\n"):
        line = line.strip()
        if line.startswith("[PASS] "):
            cases[line[7:]] = "PASS"
        elif line.startswith("[FAIL] "):
            cases[line[7:].split(": ")[0]] = "FAIL"
    return rc, cases, out


def law_lane():
    """The membership law standalone -> {assertion: status}."""
    os.makedirs(LAWPROBE, exist_ok=True)
    result = os.path.join(LAWPROBE, "result.json")
    if os.path.exists(result):
        os.remove(result)
    run("jbang sources/common/HomeMembershipLaw.java "
        "--nodeId=home.membership.law --reportDir=%s --result-out=%s"
        % (LAWPROBE, result), cwd=os.path.join(REPO, "test_graph"))
    with open(result) as fh:
        d = json.load(fh)
    return ({a["name"]: a["status"] for a in d.get("assertions", [])},
            "\n".join(d.get("logs", [])))


class Mutation:
    def __init__(self, path, old, new):
        self.path = os.path.join(REPO, path)
        self.old = old
        self.new = new
        self.backup = None

    def __enter__(self):
        with open(self.path) as fh:
            s = fh.read()
        n = s.count(self.old)
        # Mechanism C, stated as an assertion rather than a hope.
        assert n == 1, "MUTATION PATTERN matched %d times in %s (must be 1)" % (n, self.path)
        fd, self.backup = tempfile.mkstemp(suffix=".bak")
        os.close(fd)
        shutil.copyfile(self.path, self.backup)
        with open(self.path, "w") as fh:
            fh.write(s.replace(self.old, self.new))
        return self

    def __exit__(self, *a):
        shutil.copyfile(self.backup, self.path)
        os.remove(self.backup)
        return False


REPORT = []


def record(v, what, mutation, expected, before, after, extra=""):
    reddened = sorted(k for k in after if after[k] != before.get(k, after[k]))
    ok = sorted(expected) == reddened
    REPORT.append(
        "%s  %s\n"
        "    mutation: %s\n"
        "    expected to redden: %s\n"
        "    ACTUALLY reddened:  %s\n"
        "    verdict: %s%s\n"
        % (v, what, mutation, expected or "(nothing)", reddened or "(nothing)",
           "the claim reddened, and only the claim" if ok
           else "MISMATCH — read this before trusting the probe",
           ("\n    " + extra) if extra else ""))
    return ok
