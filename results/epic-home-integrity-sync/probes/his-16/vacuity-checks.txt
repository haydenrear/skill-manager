HIS-16 (#237) — vacuity checks
==============================

Produced by scratchpad/his16/vacuity.py, reproduced in full at the bottom.
Every mutation is applied to a COMMITTED tree and reverted from a byte copy
taken by the harness — never `git checkout --`, which restores to HEAD and has
eaten an agent's uncommitted work twice in this epic (DEF-035).

The three mechanisms from results/epic-home-integrity-sync/validation/
vacuity-ledger.md, and how each is answered:

  A  the probe reddens a PRECONDITION, not the claim
     -> every row names the assertion(s) that actually reddened, and the
        verdict line says whether that set is exactly the claim. A row that is
        not exactly the claim is printed as MISMATCH and kept.

  B  the FIXTURE cannot express the defect
     -> ConfinementTest's refusal case asserts its own precondition first and
        is blind to the mutation under test: it reads Confinement.covers,
        which V1 does not touch.
     -> the membership law's self-test plants DEF-047's exact residue — a unit
        gone with ONLY its .projections.json surviving — AND, since review of
        #241, a .projections.json beside every LIVE unit. The second half was
        missing, and its absence is what made V4a's first diagnosis wrong.

  C  the mutation never REACHED the code
     -> the harness asserts `s.count(old) == 1` before every mutation.

RUNNER: `jbang RunHis16.java` (ConfinementTest), plus the membership law run
standalone with --result-out.

WHY JsonContractTest IS NOT IN THE MUTATION LANE
------------------------------------------------
It drives `project register|remove|resolve|sync` on their REAL execution
paths, which is safe only because the confinement guard refuses them. Run that
suite with the guard mutated away and it does not go red: it REPRODUCES
DEF-047 against whatever checkout the JVM is standing in. Its dependence on
the guard is measured the other way round — asserted GREEN on the unmutated
tree, where all four entries reach the refusal and get exit 14 with one JSON
document carrying the typed code.

The end-to-end escape IS reproduced under control by the graph node
home-integrity/ProjectVerbStaysInItsHome, which owns a throwaway victim.

def unit_lane():
    """RunHis16 -> {case label: 'PASS'|'FAIL'}."""
    rc, out = run("jbang RunHis16.java")

class Mutation:
    def __init__(self, path, old, new):
        self.path = os.path.join(REPO, path)
        self.old = old
        self.new = new
        self.backup = None

    def __enter__(self):
        with open(self.path) as fh:
            s = fh.read()
        n = s.count(self.old)
        # Mechanism C, stated as an assertion rather than a hope.
        assert n == 1, "MUTATION PATTERN matched %d times in %s (must be 1)" % (n, self.path)
        fd, self.backup = tempfile.mkstemp(suffix=".bak")
        os.close(fd)
        shutil.copyfile(self.path, self.backup)
        with open(self.path, "w") as fh:
            fh.write(s.replace(self.old, self.new))
        return self

    def __exit__(self, *a):
        shutil.copyfile(self.backup, self.path)
        os.remove(self.backup)
        return False

def record(v, what, mutation, expected, before, after, extra=""):
    reddened = sorted(k for k in after if after[k] != before.get(k, after[k]))
    ok = sorted(expected) == reddened
    REPORT.append(
        "%s  %s\n"
        "    mutation: %s\n"
        "    expected to redden: %s\n"
        "    ACTUALLY reddened:  %s\n"
        "    verdict: %s%s\n"
        % (v, what, mutation, expected or "(nothing)", reddened or "(nothing)",
           "the claim reddened, and only the claim" if ok
           else "MISMATCH — read this before trusting the probe",
           ("\n    " + extra) if extra else ""))
    return ok
